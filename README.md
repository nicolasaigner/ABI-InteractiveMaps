## Acessando a aplicação via Web

Você pode acessar a aplicação nesse link: [https://abi-interactive-maps.vercel.app](https://abi-interactive-maps.vercel.app)

> [!IMPORTANT]
> Nenhum dado e/ou informação é capturada, todas as informações são salvas no `Armazenamento Local` do seu navegador.

## Como usar a aplicação via Desktop

Baixe a última release em [Releases](https://github.com/nicolasaigner/ABI-InteractiveMaps/releases) e baixe a versão `.exe`. 

Ao tentar executar a instalação o `Windows` vai reclamar que a aplicação não é segura. O motivo é que eu não assinei a aplicação e não pretendo até o momento fazer isso. Admito que nem procurei muito a fundo sobre isso, mas por enquanto vou deixar assim.

## Como contribuir?

Necessário o NodeJS instalado.

1. Clone o repositório:
```bash
git clone https://github.com/nicolasaigner/ABI-InteractiveMaps.git
```

2. Navegue até o diretório do projeto:
```bash
cd ABI-InteractiveMaps
```

3. Instale as dependências:
```bash
npm install
```

4. Execute o projeto:
```bash
npm start
```

5. Abra o navegador e acesse:
```
http://localhost:3000
```

### Caso queira contribuir
1. Crie um fork do repositório.
2. Crie uma branch para sua feature:
```bash
git checkout -b feature/nome-da-sua-feature
```
3. Faça suas alterações e commit:
```bash
git add .
git commit -m "Adicionando nova feature"
```

4. Faça o push para o seu fork:
```bash
git push origin feature/nome-da-sua-feature
```

5. Crie um Pull Request no repositório original.
6. Aguarde a revisão do seu código e faça as alterações necessárias.
